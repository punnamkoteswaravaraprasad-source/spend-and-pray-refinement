# Independent public demonstration

Repository: punnamkoteswaravaraprasad-source/spend-and-pray-refinement
Branch: main
Entry file: app.py

This repository deploys only the separate refinement version. It does not update the older prototype repository or spend-and-pray-mrp.streamlit.app.

Customer CSVs start empty. Included illustrative CSVs use fictional names, replacement IDs and no email addresses. The owner view defaults to Illustrative sample; switch to Customer orders for new demo purchases or Combined to inspect both. Sample records are read-only and never used as customer promo-code campaigns.

This is a classroom demonstration: no payments, no confirmation emails and no owner authentication. Use fictional details. Runtime CSVs may be reset on hosting restart/redeploy; use an external transactional database for durable production data.

Deploy with Streamlit Community Cloud: choose this repository, main, app.py, and a new app subdomain. Do not select an existing app or repository.
